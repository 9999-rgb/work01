# 单工况仿真 — 技术方案文档

## 一、主流程需求汇总

### 1.1 概述

单工况仿真流程是"水电站配电室巡检机器人仿真系统"的核心功能入口。用户通过 Web 界面配置场景与参数，提交后在 Gazebo + ROS2 环境中自动执行一次完整的巡检任务（A→B→C→D 流水线），并实时监控仿真过程，仿真结束后查看结果与回放。

### 1.2 主流程总览

```
用户 Web 端                      后端服务器（Gazebo + ROS2）
──────────                      ──────────────────────────
① 选场景布局
② 配参数 ─────────────────────→ ③ 启动仿真环境
                                        │
      ←─── WebSocket 实时推送 ─── ④ 逐点位巡检循环
                                        │
                                        ├─→ 下发巡检点 1
                                        │     ├─ A 全局导航 → 到达柜体
                                        │     ├─ B 精确定位 → 视觉伺服微调
                                        │     ├─ C 机械臂操作 → 展开+按钮旋转
                                        │     └─ D 收回转移 → 机械臂收回
                                        │
                                        ├─→ 下发巡检点 2（同上 A→B→C→D）
                                        │
                                        ├─→ 下发巡检点 N（同上）
                                        │
                                        └─→ 全部完成 / 异常终止
⑤ 实时监控（3D 视图中跟随 + 数据看板）
⑥ 查看结果 / 导出 PDF
```

### 1.3 Step 明细

| # | 步骤 | 用户操作 | 后端动作 |
|---|------|---------|---------|
| ① | **选择场景** | 从场景库选配电室 SDF 布局；支持 3D 预览 | 返回场景列表及缩略图；提供 SDF 文件供前端渲染 |
| ② | **配置参数** | 填写参数（支持阶段视图 / 功能视图切换）；可选加载工况模板 | 返回工况模板列表；保存自定义模板 |
| ②-附 | **配置扰动**（可选） | 勾选扰动类型：地面打滑、传感器噪声、通信延迟 | — |
| ③ | **提交启动** | 点击「启动仿真」 | 参数生成 YAML → 启动 Gazebo 实例 → 启动 ROS2 节点群 → 状态机自动执行 |
| ④ | **执行流水线** | —（自动执行） | 按巡检点序列逐一执行：下发点位 → A 导航 → B 精定位 → C 操作 → D 收回 → 下一巡检点（循环），详见第二章 |
| ⑤ | **实时监控** | 3D 视图同步跟随 + 数据看板实时刷新；异常时可手动终止 | rosbridge 实时推送 ROS2 话题数据至浏览器 |
| ⑥ | **查看结果** | 关键指标、轨迹图表、传感器曲线；导出 PDF | 返回结果数据；渲染 PDF 报告 |

## 二、任务执行流水线 — 逐点位巡检循环

### 2.1 整体循环逻辑

任务调度器按用户配置的巡检点序列，逐个下发点位，每个点位依次执行 A→B→C→D：

```
                        ┌─────────────────────────────────┐
                        │       任务调度器（状态机）         │
                        │  读取巡检点序列 [柜1, 柜2, 柜N]    │
                        └──────────────┬──────────────────┘
                                       │
                   ┌───────────────────┴───────────────────┐
                   ▼                                       ▼
        ┌─────────────────┐                     ┌─────────────────┐
        │  开始当前巡检点   │ ←────────────────── │  取下一个巡检点   │
        │  (设为 current)  │                     │  (current++)    │
        └────────┬────────┘                     └─────────────────┘
                 │                                          ▲
                 ▼                                          │
        ┌─────────────────┐                                 │
        │ 阶段 A: 全局导航  │                                 │
        │ 底盘从当前位置     │                                 │
        │ 导航至目标柜体     │                                 │
        └────────┬────────┘                                 │
                 │ 到达粗定位范围(±10cm)                       │
                 ▼                                          │
        ┌─────────────────┐                                 │
        │ 阶段 B: 精确定位  │                                 │
        │ 视觉伺服微调位姿   │                                 │
        │ 至操作位置(±1cm)  │                                 │
        └────────┬────────┘                                 │
                 │ 精定位完成                                  │
                 ▼                                          │
        ┌─────────────────┐                                 │
        │ 阶段 C: 机械臂操作 │                                 │
        │ 展开 → 接近 →     │                                 │
        │ 接触 → 旋转按钮   │                                 │
        └────────┬────────┘                                 │
                 │ 操作完成                                   │
                 ▼                                          │
        ┌─────────────────┐                                 │
        │ 阶段 D: 收回转移  │                                 │
        │ 机械臂收回折叠     │                                 │
        │ 底盘恢复导航权限   │                                 │
        └────────┬────────┘                                 │
                 │                                          │
                 ▼                                          │
        ┌─────────────────┐     还有未执行的巡检点             │
        │  检查巡检点序列   │ ─────────────────────────────────┘
        │  是否还有剩余？   │
        └────────┬────────┘
                 │ 全部完成
                 ▼
        ┌─────────────────┐
        │    任务结束       │
        │  写入结果到数据库  │
        └─────────────────┘
```

各阶段全程伴随：**安全监控**（碰撞检测、超时检测、异常力矩）、**动态避障**（激光雷达实时监测）、**数据记录**（轨迹、关节角/力矩、传感器、事件日志）。

### 2.2 逐点位详细时序（以单个巡检点为例）

```
时间轴 ──────────────────────────────────────────────────────────►

 ┌─ 任务调度器 ──────────────────────────────────────────────────┐
 │ 下发巡检点  ──┐                                                │
 │  (柜体 N)     │                                                │
 │              ▼                                                │
 │      设置目标位姿 (x, y, yaw)                                   │
 │      通知各节点进入"阶段 A"                                      │
 └──────────────────────────────────────────────────────────────┘
        │
 ┌─ 阶段 A: 全局导航 ────────────────────────────────────────────┐
 │  ① Nav2 接收目标位姿                                           │
 │  ② 全局路径规划 → 生成行驶轨迹                                  │
 │  ③ 差速底盘执行速度指令 (v, ω)                                  │
 │  ④ 局部避障控制器实时监测激光雷达点云                            │
 │  ⑤ 动态障碍物 → 重规划或停车等待                                │
 │  ⑥ 到达目标柜体附近（粗定位 ±10cm）→ 通知任务调度器              │
 └──────────────────────────────────────────────────────────────┘
        │
 ┌─ 阶段 B: 精确定位 ────────────────────────────────────────────┐
 │  ① 任务调度器下发"精定位"指令                                   │
 │  ② 深度相机识别柜体面板特征（AR标签/二维码/特征点）               │
 │  ③ 计算当前位姿与目标位姿的偏差                                  │
 │  ④ 视觉伺服循环微调底盘位姿                                     │
 │  ⑤ 精定位完成（±1cm, ±2°）→ 通知任务调度器                      │
 │  ⑥ 校验安全距离（底盘-柜体 > 阈值，机械臂工作空间无干涉）         │
 └──────────────────────────────────────────────────────────────┘
        │
 ┌─ 阶段 C: 机械臂展开与操作 ─────────────────────────────────────┐
 │  ① 任务调度器下发"操作模式"，发送目标按钮位姿（相对机械臂基座）    │
 │  ② MoveIt2 逆运动学求解 + 碰撞检测（自干涉 + 环境干涉）          │
 │  ③ 生成无碰撞关节轨迹 → 机械臂关节依次执行 → 展开至预操作姿态     │
 │  ④ 末端低速接近按钮（位置控制阶段）                              │
 │  ⑤ 接触检测：力/电流突变的阈值判别 → 确认接触                     │
 │  ⑥ 切换力位混合控制：保持接触力恒定 + 按目标角度旋转按钮           │
 │  ⑦ 旋转到位判定：角度反馈 + 力矩阈值双重确认                      │
 │  ⑧ 操作完成 → 通知任务调度器                                    │
 └──────────────────────────────────────────────────────────────┘
        │
 ┌─ 阶段 D: 收回与转移 ──────────────────────────────────────────┐
 │  ① 任务调度器下发"收回指令"                                     │
 │  ② 机械臂按规划轨迹收回至折叠/运输姿态                           │
 │  ③ 碰撞检测确认无干涉 → 底盘恢复导航权限                         │
 │  ④ 任务调度器检查巡检点序列：                                   │
 │     · 还有剩余 → 取下一个巡检点 → 循环回阶段 A                   │
 │     · 全部完成 → 任务结束                                       │
 └──────────────────────────────────────────────────────────────┘
```

### 2.3 异常处理（贯穿全程）

每一步发生异常时，按用户配置的策略处理：

| 异常类型 | 检测方式 | 急停 | 回退重试 | 跳过继续 |
|---------|---------|------|---------|---------|
| 路径规划失败 | 超时无法到达 | √ 终止任务 | √ 重规划 N 次 | √ 标记跳过 |
| 定位失败 | 视觉伺服超迭代次数 | √ | √ | √ |
| 碰撞事件 | 力/碰撞传感器触发 | √ 立即停止 | — | — |
| 力矩超限 | 关节力矩 > 阈值 | √ | — | — |
| 操作超时 | 阶段 C 超过时限 | √ | √ 重试 1 次 | √ |
| 通信中断 | 节点心跳丢失 | √ | — | — |

---

### 2.4 阶段 A：全局导航（细化）

机器人从当前位置导航至任务调度器下发的目标巡检柜体。

```
接收目标柜体位姿 → Nav2 全局路径规划 → 差速底盘速度指令
→ 激光雷达实时避障 → 到达粗定位范围（±10cm）→ 通知任务调度器
```

核心参数：

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 巡检点序列 | — | 目标柜体列表，按顺序执行 |
| 路径规划算法 | TEB | A\* / Dijkstra / TEB / Smac |
| 底盘最大行驶速度 | 0.5 m/s | 0.2 ~ 1.0 m/s |
| 底盘最大旋转角速度 | 1.0 rad/s | 0.5 ~ 2.0 rad/s |
| 路径规划超时 | 10 s | 5 ~ 60 s |
| 是否允许倒车 | 是 | 是 / 否 |
| 粗定位容差 | ±10 cm | ±5 ~ ±20 cm |

### 2.5 动态避障（贯穿导航全过程）

在全局导航和转移期间持续运行，处理动态障碍物。

```
激光雷达实时扫描 → 发现动态障碍物 → 避障策略判断
→ 绕行 / 停车等待 / 减速通过 → 障碍物消失后恢复原路径
```

核心参数：

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 避障预警距离 | 1.5 m | 0.5 ~ 3.0 m |
| 局部避障算法 | DWA | DWA / TEB / MPC |
| 障碍物膨胀半径 | 0.3 m | 0.1 ~ 0.5 m |
| 避障重规划超时 | 3 s | 1 ~ 10 s |
| 避障策略 | 绕行 | 绕行 / 停车等待 / 减速通过 |
| 动态障碍物最小安全距离 | 0.3 m | 0.1 ~ 0.5 m |

### 2.6 阶段 B：精确定位（细化）

粗定位完成后，通过视觉伺服将机器人微调至精确操作位置。

```
任务调度器下发"精定位"指令
→ 深度相机扫描柜体面板 → 识别 AR标签 / 二维码 / 特征点
→ 计算位姿偏差 → 视觉伺服循环微调
→ 精定位完成（±1cm, ±2°）
→ 校验安全距离（底盘-柜体、机械臂工作空间无干涉）
→ 通知任务调度器 → 进入阶段 C
```

核心参数：

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 深度相机识别精度 | 0.5 cm | 自定义 |
| 精定位位姿容差 | ±1 cm, ±2° | 自定义 |
| 视觉伺服最大迭代次数 | 50 | 10 ~ 200 |
| 末端-柜体面板最近距离 | 15 cm | 5 ~ 30 cm |
| 定位校验安全距离阈值 | 10 cm | 5 ~ 20 cm |
| 启用机械臂末端相机辅助 | 否 | 是 / 否 |

### 2.7 阶段 C：机械臂展开与操作（细化）

精定位完成后，任务调度器下发按钮操作指令。

```
任务调度器下发"操作模式" + 目标按钮位姿（相对机械臂基座坐标）
→ MoveIt2 逆运动学求解 → 碰撞检测（自干涉 + 环境干涉）
→ 生成无碰撞关节轨迹 → 各关节执行 → 展开至预操作姿态
→ 末端低速接近按钮（位置控制阶段）
→ 力/力矩传感器实时监测
→ 接触检测触发（力阈值 / 电机电流突变）
→ 确认接触 → 切换力位混合控制：
    · 控制维度：沿按钮法向保持恒定接触力
    · 运动维度：绕按钮轴线执行目标旋转角度
→ 旋转到位判定（角度反馈 + 力矩阈值双重确认）
→ 通知任务调度器 → 进入阶段 D
```

核心参数：

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 机械臂折叠姿态 | 各关节 0° | 自定义多关节角度 |
| 机械臂操作姿态 | — | 目标末端位姿 (x,y,z,roll,pitch,yaw) |
| 运动学求解算法 | Trac-IK | KDL / Trac-IK / BioIK |
| 运动速度缩放系数 | 0.3 | 0.1 ~ 1.0 |
| 自碰撞安全距离 | 2 cm | 1 ~ 5 cm |
| 环境碰撞安全距离 | 5 cm | 3 ~ 10 cm |
| 末端接近速度 | 0.03 m/s | 0.01 ~ 0.1 m/s |
| 接触检测力阈值 | 5 N | 2 ~ 10 N |
| 接触检测电流突变阈值 | 0.3 A | 0.1 ~ 1.0 A（辅助判断） |
| 力位混合控制保持力 | 5 N | 3 ~ 8 N |
| 按钮旋转最大力矩 | 3 Nm | 0.5 ~ 5 Nm |
| 按钮旋转目标角度 | 90° | 0° ~ 360° |
| 旋转到位角度容差 | ±2° | ±1° ~ ±5° |
| 操作超时 | 30 s | 10 ~ 120 s |

### 2.8 阶段 D：收回与转移（细化）

操作完成后，机械臂收回至运输姿态，任务调度器决定下一步。

```
任务调度器下发"收回指令"
→ MoveIt2 规划收回轨迹 → 碰撞检测
→ 生成无碰撞轨迹 → 各关节执行 → 收回至折叠/运输姿态
→ 碰撞检测确认无干涉
→ 任务调度器决策：
    · 巡检点序列还有剩余 → 取下一个巡检点 → 下发新目标 → 循环回阶段 A
    · 巡检点序列全部完成 → 任务结束 → 写入结果
→ 阶段 D 串行/并行选项：
    · 串行（默认）：机械臂完全收回后方启动底盘
    · 并行：机械臂开始收回后底盘即可低速启动转移
```

核心参数：

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 机械臂收回姿态 | 各关节 0° | 自定义 |
| 收回速度缩放系数 | 0.5 | 0.1 ~ 1.0 |
| 收回过程碰撞检测 | 开启 | 开启 / 关闭 |
| 收回完成前底盘启动 | 否（串行） | 串行 / 并行 |

### 2.9 全局参数

| 参数 | 默认值 | 范围 |
|------|--------|------|
| 总任务超时 | 300 s | 60 ~ 600 s |
| 异常处理策略 | 急停 | 急停 / 回退重试 / 跳过继续 |
| 最大重试次数 | 1 | 0 ~ 5 |
| 阶段间串行/重叠 | 串行 | 串行 / 允许重叠 |
| 随机种子 | 42 | 任意整数 |

### 2.10 新增 ROS2 话题：巡检点位状态

为支持 Web 端实时显示当前巡检进度及点位切换，新增两个话题：

| ROS2 Topic | 消息类型 | 用途 |
|-------------|---------|------|
| `/mission/current_waypoint` | `std_msgs/Int32` | 当前正在执行的巡检点序号 |
| `/mission/waypoint_status` | `自定义消息 {id, status, timestamp}` | 每个巡检点的状态：pending / navigating / positioning / operating / retracting / done / failed |

## 三、参数组织方式

### 3.1 双视图切换

参数配置页提供两种视图，共用同一套底层数据模型：

- **阶段视图（时序视角）**：按 A→B→C→D 流水线分标签页，适合首次配置和分步调试
- **功能视图（动作视角）**：按巡检 / 定点操作 / 动态避障 / 狭小通行四类动作分组，适合专项能力评估

两种视图的数据实时同步，切换时不丢失已填写内容。

```
┌─────────────────────────────────────────────┐
│  参数配置          [阶段视图 ▾]  [功能视图]    │
├─────────────────────────────────────────────┤
│                                              │
│  (当前视图下的参数表单)                         │
│                                              │
│  [从工况模板加载...]    [保存为工况模板...]     │
└─────────────────────────────────────────────┘
```

### 3.2 两种视角的映射

```
              时序维度 (阶段)
              ──────────────────────────────►
              A            B         C         D

功  巡检      ████████████████████░░░░░░░░░████████   ← 导航 + 转移
能  定点操作  ░░░░░░░░░░░░░░█████████████████░░░░░░░   ← 定位 + 操作
维  动态避障  ░░░░░░░░█████████████████████████░░░░░   ← 跨 A+B
度  狭小通行  █████████████████████████████████████   ← 跨全程
    全局参数  █████████████████████████████████████   ← 跨全程
    扰动注入  █████████████████████████████████████   ← 跨全程
```

### 3.3 扰动注入（可选）

| 扰动类型 | 参数 | 默认值 | 范围 |
|---------|------|--------|------|
| 地面打滑 | 摩擦系数 μ | 0.7 | 0.3 ~ 1.0 |
| 传感器噪声 | 噪声等级 | 中 | 低 / 中 / 高 |
| IMU 漂移 | 漂移斜率 | 0.001°/s | 自定义 |
| 通信延迟 | 延迟时间 | 0 ms | 0 ~ 500 ms |

### 3.4 工况模板

- **保存模板**：名称 + 分类（正常工况 / 边界工况 / 扰动工况 / 故障工况）+ 备注
- **加载模板**：从模板列表搜索、选择、一键加载全部参数
- **底层数据**：JSON/YAML，前端与后端共用同一 schema

## 四、Web ↔ Gazebo 数据通路

### 4.1 通信架构

```
浏览器 ←──WebSocket──→ rosbridge ←──ROS2 Topics──→ Gazebo/ROS2 节点
```

### 4.2 话题映射

| ROS2 Topic | 消息类型 | 用途 | 更新频率 |
|-------------|---------|------|---------|
| `/odom` | `nav_msgs/Odometry` | 机器人里程计位姿 | 50 Hz |
| `/joint_states` | `sensor_msgs/JointState` | 机械臂各关节角度/速度 | 100 Hz |
| `/scan` | `sensor_msgs/LaserScan` | 激光雷达点云 | 10 Hz（降采样后） |
| `/tf` | `tf2_msgs/TFMessage` | 各坐标系变换（3D渲染用） | 30 Hz |
| `/force_sensor` | `geometry_msgs/Wrench` | 末端力/力矩传感器 | 100 Hz |
| `/collision_event` | `自定义消息` | 碰撞检测事件 | 事件触发 |
| `/mission/phase` | `std_msgs/String` | 当前任务阶段（A/B/C/D） | 状态变化时 |
| `/metrics` | `自定义消息` | 实时指标（轨迹RMSE、安全距离） | 1 Hz |

### 4.3 3D 场景渲染数据流

```
SDF/URDF 文件 ──→ 服务端转换（urdf2gltf/sdf2gltf）
        │
        ▼
   glTF 模型 ──→ 浏览器 Three.js 加载
        │
        ▼
  rosbridge ──→ /tf + /joint_states ──→ 驱动 3D 模型关节动画
```
