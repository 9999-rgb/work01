## 水电站配电室巡检机器人仿真系统运行流程

### 一、系统启动阶段

```
┌─────────────────────────────────────────────────────────────┐
│  1. 加载场景与模型                                             │
│     • 启动 Gazebo Harmonic 仿真引擎                           │
│     • 导入配电室 SDF 场景（开关柜阵列、运维通道、电缆沟）          │
│     • 加载机器人 URDF（差速轮底盘 + JAKA 机械臂 + 传感器）        │
│     • 初始化物理引擎（DART）、碰撞检测、传感器仿真插件             │
├─────────────────────────────────────────────────────────────┤
│  2. 启动 ROS2 节点层                                           │
│     • 导航节点（Nav2）：地图服务、定位（AMCL）、路径规划、避障      │
│     • 规划节点（MoveIt2）：机械臂运动学、轨迹规划、碰撞检测         │
│     • 控制节点：底盘差速控制器、机械臂关节控制器、力控模块           │
│     • 感知节点：激光雷达点云处理、深度相机图像识别、IMU数据融合      │
│     • 任务调度节点：状态机管理、任务序列编排、异常处理              │
├─────────────────────────────────────────────────────────────┤
│  3. 参数配置加载                                               │
│     • 读取工况配置文件（空间约束、安全距离阈值、速度限制、力控阈值）   │
│     • 加载校准后的物理参数（摩擦系数、按钮阻力矩、传感器噪声模型）    │
└─────────────────────────────────────────────────────────────┘
```

### 二、任务执行阶段（以"巡检+定点操作"为例）

```
┌─────────────────────────────────────────────────────────────┐
│  阶段 A：全局导航                                               │
│  ─────────────────                                             │
│  • 任务调度节点发布目标巡检柜位姿（x, y, yaw）                   │
│  • Nav2 全局路径规划 → 生成底盘行驶轨迹                          │
│  • 局部避障控制器实时监测激光雷达点云                             │
│  • 差速底盘执行速度指令（v, ω）→ Gazebo 物理仿真运动              │
│  • 动态障碍物（行人/其他机器人）出现时 → 重规划或停车等待            │
├─────────────────────────────────────────────────────────────┤
│  阶段 B：精确定位                                               │
│  ─────────────────                                             │
│  • 底盘到达目标柜体附近（粗定位 ±10cm）                          │
│  • 深度相机识别柜体面板特征（按钮区域、二维码/AR标签）              │
│  • 视觉伺服微调底盘位姿 → 精定位（±1cm，±2°）                    │
│  • 校验安全距离（底盘与柜体 > 阈值，机械臂工作空间无干涉）          │
├─────────────────────────────────────────────────────────────┤
│  阶段 C：机械臂展开与操作                                        │
│  ─────────────────                                             │
│  • 任务调度切换至"操作模式"，发送目标按钮位姿（相对机械臂基座）      │
│  • MoveIt2 进行运动学求解 + 碰撞检测（自干涉 + 环境干涉）          │
│  • 生成无碰撞关节轨迹 → 机械臂各关节执行                         │
│  • 末端接近按钮过程中：位置控制 → 接触检测（力/电流突变）           │
│  • 接触确认后切换力位混合控制：保持接触力恒定 + 执行旋转角度        │
│  • 旋转到位判定（角度反馈 + 力矩阈值）→ 操作完成确认               │
├─────────────────────────────────────────────────────────────┤
│  阶段 D：收回与转移                                              │
│  ─────────────────                                             │
│  • 机械臂按规划轨迹收回至折叠/运输姿态                            │
│  • 碰撞检测确认无干涉后，底盘恢复导航权限                          │
│  • 任务调度发布下一巡检点 → 循环阶段 A                            │
└─────────────────────────────────────────────────────────────┘
```

### 三、扰动注入与边界测试（模型校准与批量仿真阶段）

```
┌─────────────────────────────────────────────────────────────┐
│  单工况仿真运行                                                 │
│  ───────────────                                               │
│  • 从标准化工况库加载一组参数配置                                │
│  • 按上述 A→B→C→D 流程执行一次完整任务                          │
│  • 实时记录：底盘轨迹、机械臂关节角/力矩、末端位姿、传感器数据      │
│  • 检测异常：碰撞、超时、力矩超限、定位失败、操作失败               │
│  • 输出单次仿真结果：成功/失败、关键指标数值                        │
├─────────────────────────────────────────────────────────────┤
│  批量遍历仿真                                                   │
│  ───────────────                                               │
│  • 工况调度器自动遍历参数网格（如安全距离 5~20cm 步进 1cm）         │
│  • 每个参数组合重复运行 N 次（蒙特卡洛，考虑随机扰动）              │
│  • 并行运行多个 Gazebo 实例（如资源允许）                         │
│  • 汇总统计：任务完成率、轨迹稳定性 RMSE、安全距离合格率等          │
├─────────────────────────────────────────────────────────────┤
│  边界搜索                                                       │
│  ───────────────                                               │
│  • 对关键参数进行二分/梯度搜索，定位任务失败临界点                 │
│  • 例如：最小通道宽度、最大允许按钮阻力矩、最高行驶速度              │
│  • 输出边界报告：安全运行包络（Safe Operating Envelope）           │
└─────────────────────────────────────────────────────────────┘
```

### 五、典型运行模式

| 模式 | 用途 | 运行方式 |
|------|------|---------|
| **单工况调试** | 算法开发、参数调优 | 手动配置，实时可视化，单步执行 |
| **标准工况验证** | 功能验收、回归测试 | 加载标准工况库，自动执行，输出报告 |
| **边界搜索** | 安全包络确定 | 自动参数扫描，定位失效临界点 |
| **蒙特卡洛批量** | 可靠性评估 | 随机扰动注入，大规模统计，置信区间分析 |
| **对比评估** | 策略 A/B 测试 | 相同工况集下对比不同控制/规划策略指标 |

### 六、关键交互时序（以按钮操作为例）

```
时间轴 ──────────────────────────────────────────────────────►

底盘停靠到位 ──┐
              ▼
机械臂展开 ─────┤
              ▼
末端接近按钮 ───┤  ← 视觉伺服引导
              ▼
接触检测 ───────┤ [需求.md](%E9%9C%80%E6%B1%82.md) ← 力/电流阈值触发
              ▼
力位混合控制 ───┤  ← 保持接触力 + 旋转
              ▼
旋转到位确认 ───┤  ← 角度+力矩双重判定
              ▼
机械臂收回 ─────┤
              ▼
底盘转移 ───────┘

各阶段安全监控（碰撞检测、超时检测、异常力矩）持续运行
异常时触发紧急停止或回退策略
```
