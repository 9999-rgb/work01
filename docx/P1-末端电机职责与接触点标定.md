## 0. 本阶段结论速览

- 五个末端电缸关节全部可通过各自专用 JTC action 单独运动，且"每个关节只动
  自己那根连杆"已逐一实测确认（见 §1 表）。
- **关键控制合同**：三个末端控制器均 `allow_partial_joints_goal=false`，
  给单个关节发 goal 不会被执行（实测"秒成功、零位移"）。**每个 goal 必须带全
  该控制器全部关节**（被测关节给目标值，其余保持当前），与 MoveIt 生产路径一致。
- 职责认定（§3）：右侧解锁 = `r_three_cyl_finger3_joint`（短级，串在 finger2 上）；
  右支撑 = `r_three_cyl_finger2_joint`；右夹爪 = `r_three_cyl_finger1_joint`；
  左支撑 = `l_two_cyl_finger1_joint`；左夹爪 = `l_two_cyl_finger2_joint`。
  依据结构 + 历史工具业务点标定 + 本次运动实测（§3），**最终工作位置与接触点
  由 §7.2 db1 逐阶段现场测试封定**（每项封定后才写正式动作序列，符合 §2.4/§7.2）。
- 右把手解锁区中心复核 = (0.115, 4.693, 0.952)，**不引用 b1p**（§4）。

## 1. 单关节辨识实测（Gazebo，活栈）

命令通道：`/xczs/three_cylinder_controller/follow_joint_trajectory`（右）、
`/xczs/two_cylinder_controller/follow_joint_trajectory`（左）。控制器均为
computed-torque 型 JTC：`command_interfaces: effort` + 每关节 PID gains，
轴 0 0 −1（棱柱沿工具鼻向伸出）。工具停靠位：右基座 (1.383, 5.034, 2.024)、
左基座 (1.308, 3.770, 1.985)。

| 关节 | 控制器内 index | 移动连杆 | 行程 (m) | 运动学归属 | 实测响应 | 证据（关节值 / 连杆世界位移） |
|---|---|---|---|---|---|---|
| `r_three_cyl_finger1_joint` | 右 0 | `r_three_cyl_finger1` | [0, 0.12] | 直连 base，基座系 x=+0.034 | 伸 0→0.01003 干净到位 error 0；收回到 ~0 | 连杆位移 \|Δ\|=0.0100，基座 0 动 |
| `r_three_cyl_finger2_joint` | 右 1 | `r_three_cyl_finger2` | [0, 0.12] | 直连 base，x=−0.034；**finger3 的父级** | **伸出极慢**（短窗 0 位移，持 0.02 目标约 40 s 才爬到 8 mm）；**收回快且干净**（8.14 mm→0.00009，error 0） | 同上；关节可动、方向正确 |

实测伸出行程方向（世界，取停靠位基座→连杆）：右 ≈ (−0.35, +0.57, +0.68)、
左 ≈ (−0.75, −0.36, +0.56)（单位向量，**随停靠姿态变化**，仅供辨识"哪个关节动
哪根杆"用，不作为作业姿态结论）。工具局部系中所有杆都沿工具基座 −Z 伸出
（URDF `axis 0 0 -1` 与实测一致），即"工具鼻向"。

### 1.1 复位与静息位（2026-09-03 实测）

把全部五关节命令到 0 后：

| 关节 | 命令目标 | 实际静息 |
|---|---|---|
| 右 finger1/2/3 | 0 | ≈ 0.000（右 I=60 可钉住） |
| 左 finger1 | 0 | ≈ 0.0022–0.0025 |
| 左 finger2 | 0 | ≈ 0.0036–0.0037 |

左杆 I=0 的弱增益对重力欠校正，静息 ~2–4 mm 与既有记录（"静息位 2.5–4 mm"）
一致；右杆 I=60 能钉到 0。此余差小于工具 tip 附着容差，操作语义不受影响，但
**任何"收回"判定都要按各自的静息基线做，不能拿 0 当唯一收回证据**。

### 1.2 控制响应不对称（进入 §7 前必须知道的坑）

- 右 finger2 伸出在停靠姿态**明显偏慢**（重载/姿态相关），收回却很快。同一根杆
  历史在柜前接触作业时达到过 0.004 m+，说明杆本身无故障；慢的是当前姿态下的
  伸出方向（逆重力/贴阻力）。**§7.2 工作位置测试须在正式作业姿态下、用足够
  长的执行窗口判定伸出到位，不能用短窗秒判"卡死"。**
- 左两杆无积分项，到位有 ~2–4 mm 静差与轻微过冲 → §4.2/§5 抓取判据的距离
  阈值应从既有 `0.02 m` 起步、实测收紧，不要把 `±0.003` 标定容差套到弱增益杆上。
- 本次实测由探针以"全关节 goal + 2 s 轨迹"驱动；正式流程仍走 operator 既有
  有界小步 + 自身校验路径（§3.3），不改变公共接口。

## 3. 职责认定（最终工作位置由 §7.2 现场封定）

判断依据（结构 + 历史标定 + 本次实测，非仅凭名称）：

- **右解锁推进**：短级 `r_three_cyl_finger3_joint`。25.4 mm 短行程适合"伸入
  逻辑解锁区作小步推进、不过冲"；杆质 2 g 碰撞温和；AGENT §2 亦提示短级为
  首选假设——本次实测确认它能独立、可控运动（§1）。它串在 finger2 上，解锁
  阶段须先摆好 finger2（收回/定位）使 finger3 杆端对准解锁区。
- **右夹爪**：`r_three_cyl_finger1_joint`。历史 `tool_tip_position`
  [0.0265, −0.061735, −0.3885]（右工具最深业务点，按压/抓取共用）落在 finger1
  杆侧（基座系 x=+0.034）；finger1 是右工具传统"最深接触杆"。抓取 = 该杆端
  贴右把手立板前缘 (0.099, 4.693, 0.952)，接触达标后再双手 attach。
- **右支撑**：`r_three_cyl_finger2_joint`。另一根长杆，抵柜面右支撑点
  (0.099, 4.693, 0.902)；与 unlock（finger3）分属不同阶段，职责不混淆。
  （若 §7.2 stage-5 抓取需 finger1+finger2 双侧贴板，再把支撑/夹爪在两者间对调，
  判定以"两杆都真实贴板"优先。）
- **左夹爪**：`l_two_cyl_finger2_joint`。历史 `tool_tip_position`
  [−0.034, −0.061735, −0.3885] 与 finger2 基座系 x 完全一致，左最深业务杆。
- **左支撑**：`l_two_cyl_finger1_joint`。另一根长杆，抵 (0.099, 4.107, 0.902)。

接触链接 = 各关节对应的移动连杆（§1 表第二列），即 P1 职责"接触链接"。
`unlock_contact_link = r_three_cyl_finger3`、`support_contact_link` =
对应支撑杆连杆、`gripper` 抓取证据 = 对应杆端到把手立板的接触距离。

## 4. 右把手解锁区复核（不引用 b1p）

- **`b1p`（`*p`）指示灯现状**：位于右把手立板前缘顶部内侧，世界约
  (0.099, 4.685, 1.000)（关位；Y≈右把手 y+0.008、Z≈把手顶+0.03），是一颗
  0.05 kg、3 mm 行程 prismatic 帽——**当前未提交改动把它做成了"可下压解锁按钮"，
  属 §3.3 要撤销的语义**。P0 §2.2 明确 `*p` 不是按钮、不进 operable。
- **解锁逻辑区中心**：`(0.115, 右把手 y=4.693, 右把手 z=0.952)` = 右把手立板
  前缘 x=0.099 **以东 0.016**、把手立板 y/z 中心高度。该区无可见执行器/按钮；
  插件以"解锁电机接触链接世界位置进入该区（距离容差）"+"解锁电机实际伸出量"
  联合作为解锁物证（§3.1 合同）。b1p 世界位置 (0.099, 4.685, 1.000) 距区中心
  0.056 m，**即使把 b1p 当按钮压也不构成该区的接触证据**——两者几何上不重合。
- 正式作业中解锁 = 右臂转至解锁角 → 解锁电机 (finger3) 沿 −X 推进至其杆端进
  入上述逻辑区并满足接触/伸出阈值；达到才释放轨道锁止，达不到就失败（不许
  强制解锁）。
