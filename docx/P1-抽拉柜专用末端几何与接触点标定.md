## 2. 串联关系与 FK 链（冻结）

右解锁杆挂在右支撑杆之下（tools.xacro 行 210-214）：

```text
right_tool_base --(r_three_cyl_finger2_joint, prismatic z-, 0..0.12)-->
  r_three_cyl_finger2 --(r_three_cyl_finger3_joint, prismatic z-, 0..0.0254,
  origin [-0.012, 0.082, -0.05245])--> r_three_cyl_finger3 --(接触点局部
  [0,0,-0.013002])--> unlock_contact_point
```

- 解锁触点在工具基座零位系：`[-0.046, 0.020265, -0.358952]`
  （= finger2 原点 [-0.034,-0.061735,-0.2935] + finger3 原点
  [-0.012,0.082,-0.05245] + 杆端 [-0.013002]）。
- **任何世界坐标计算必须先加父级 finger2 实时伸出量再算 finger3 行程**
  （AGENT §2.2 末条；适配器注释与 007 后代码已执行此语义，live 复核项）。

## 3. 杆列几何（冻结）

- 左/右工具各列横向偏移 ±0.034 m → 杆列间距 **0.068 m**（与 AGENT §4.3
  “把手钩点—侧缝支撑点横向间距 0.068”匹配）。
- 左工具 `tool_roll_offset = π`、右工具 `0`：左工具绕作业轴翻转 180°，
  使左支撑列位于钩取列的外侧（西侧缝方向）；右工具不翻转，右支撑列位于
  钩取列的外侧（东侧缝方向）。两侧形成“钩取贴把手、支撑在把手外侧缝隙”
  的同构镜像。
- 所有杆沿工具局部 -z 伸出；杆行公共横向偏置 y_local=-0.061735（finger3 行
  例外 y=+0.020265，见 §4）。

## 4. 右解锁按钮接触区（语义冻结，坐标待 live 封定）

- b1p/s1p/s2p/s3p/m1p 一律为固定指示灯（并入抽屉本体，无行程、不进
  operable、不产出解锁证据）——AGENT §0.1/§2.3，已由 2026-09-03 改动落实。
- 可见 STL 上无按钮特征（b1.STL 鳍面无按钮凸起），按 AGENT §4.4 在“真实按钮
  位置”使用不可见接触区/逻辑区表达按钮本体，不改可见外形。
- 触点行位：finger3 杆行在工具基座 y_local=+0.020265（其余杆行 -0.061735），
  finger3 触点横向列 x_local=-0.046（比支撑列 -0.034 更外 12 mm）。工作位姿下
  finger3 杆端应在右把手本体上形成按压目标（AGENT §4.4：按钮目标点由“右钩爪
  已钩住、右支撑已入缝”的最终构型反推，禁止先按按钮再返回把手）。
- 解耦语义（AGENT §2.2 与插件 2026-09-03 注释一致）：解锁放行 = 请求方
  接触链接世界位姿进入解锁逻辑区 + 电机实际伸出 ∈ [floor, ceiling)，
  **pressed=true 请求本身不构成物理证据**。当前区中心候选值
  (0.115,4.693,0.952)（前缘外 0.016 浮动点）与 AGENT“按钮在把手本体上”
  不符，作为 §P2 修订对象：新按钮点候选 = 右鳍本体某面 + 法向，
  在 live 封定前按“鳍外表面不可见局部接触区”实施（§P2 详述）。

| 左钩取 finger2 | 0.0 | 0.010 | 0.12 | 旧“压前脸 2mm”语义；新钩持位 live 封定 |

候选工作位不等于最终标定：侧缝中心/进入深度/接触法向、钩持面落点

（AGENT §4.2-4.4 / §7.2；db1 调试步骤 4-7）。每个工作位须保留机械行程
余量（finger1/2 上限 0.12 已留 ~4 倍余量，finger3 上限 0.0254 工作 0.008
余量 3 倍）。

## 6. 控制与标定陷阱（沿用有效项）

- JTC 控制器 `allow_partial_joints_goal=false`：每次 goal 必须携带全关节集
  （左右缸 I=0 静差 2-4 mm，回位判断用静息基线而非绝对 0）。
- 右侧 finger2 在收纳姿态下伸出偏慢（重力/摩擦），阶段切换要给足 settle。
- 闭环手指（finger2/finger3 校准时闭合位存在接触碰撞）→ ODE 推到接触平衡
  静息位 ~2.5-4 mm；`tool_tip_calibration_joint_tolerance=0.006` 覆盖静差。
- 硬门限（007 后）：支撑/钩取接触 0.008、臂位姿 0.008 / 0.02 rad / 漂移
  0.003 / 稳定窗 0.3 s；`drawer_grasp_outward_offset=0.005`、
  `drawer_grasp_press_depth=0.002`（新钩持语义下值复核）。
- 阶段保持契约（AGENT §6.3）：进入下一阶段不得把上一阶段电缸隐式归零。
