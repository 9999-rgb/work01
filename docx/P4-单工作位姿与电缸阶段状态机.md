### cap1（§8.3 单工作位姿就位）—— PASS ✅

- 驱动：`db1_stage_cap_driver.py --cap 1`；goal status 4 / success True /
  error_code 0；`debug_stage_cap=1 reached: both arms reached the single
  drawer work pose with all rod actuators retracted (drawer untouched,
  still latched closed)`。
- 双臂一次到位的执行路径：锚定（op-start 轨位 0.0008 m）→ 并发直接 FJT
  双臂到位（left 16 s / right 14.5 s，无 goal_tolerance，轨迹时间到即
  goal reached）→ settle 2 s 后进入 0.3 s 稳定带采样。
- 稳定带实测（几何门禁未放宽：position 0.008 / orientation 0.02 /
  motion 0.003）：
  - `drawer work pose left`：position ≤ 0.0039 m，orientation ≤ 0.0074 rad，
    motion ≤ 0.0025 m；
  - `drawer work pose right`：position ≤ 0.0044 m，orientation ≤ 0.0148 rad，
    motion ≤ 0.0016 m。
- 抽屉保持闩定：topic `state closed@0.0008 → closed@0.0007 m`（peak
  0.0019 m），final_verified True / physical_outcome True / transport_ok
  True。
- 首轮失败根因（本 cap 修掉并复证）：直接 FJT 无 goal_tolerance → 轨迹
  时间到即"Goal reached"，此时 PID 仍在收敛瞬态；旧 verify 首样本
  0.05 s 后即抛（0.0084 m 超 0.008）。新 verify 语义 = 先 settle
  （2 s 窗口容忍收敛）再要求连续 0.3 s 稳定带内（离带即抛并报逐轴 delta），
  收敛瞬态不再误杀，几何门禁数值不变。
- 修复前失败日志（对照）：`Drawer 'drawer work pose left' position error
  0.008401 m ... motion 0.000000`（throw 于控制器 goal-reached 后 0.05 s；
  ERROR 时间戳 = recovery 83 s 后的打印时刻，非抛点）。
