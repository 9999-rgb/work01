# XCZS Inspection Robot

ROS 2 Humble and Gazebo Classic simulation for the XCZS inspection robot.

## Workspace Layout

- `xczs_inspection_robot_description`: URDF, meshes, collision meshes and world
- `xczs_inspection_robot_control`: C++ keyboard controller and unified launch

`build/`, `install/` and `log/` are generated by `colcon` and are not source
directories.

## Build

```bash
cd /home/live/work01
source /opt/ros/humble/setup.bash
PATH=/usr/bin:/opt/ros/humble/bin:/bin \
  colcon build \
  --packages-select \
  xczs_inspection_robot_description \
  xczs_inspection_robot_control \
  --symlink-install \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
```

## Start

```bash
cd /home/live/work01
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch xczs_inspection_robot_control inspection_robot.launch.py
```

The launch file starts Gazebo, spawns the robot and opens the keyboard
controller in a separate terminal.

Useful launch arguments:

```bash
# Start without the Gazebo GUI.
ros2 launch xczs_inspection_robot_control inspection_robot.launch.py gui:=false

# Start Gazebo without opening the keyboard-control terminal.
ros2 launch xczs_inspection_robot_control inspection_robot.launch.py teleop:=false

# Start with Gazebo physics paused.
ros2 launch xczs_inspection_robot_control inspection_robot.launch.py paused:=true
```

## Keyboard Control

- `W` / `S`: move the base forward / backward
- `A` / `D`: turn the base left / right
- `X` or `Space`: stop the base
- `1` ... `6`: select an arm joint
- `[` / `]`: decrease / increase the selected joint angle
- `R`: reset all arm joints to zero
- `O` / `P`: open / close the gripper
- `H` or `?`: display help
- `Q` or `Ctrl-C`: stop the base and close the controller

The base automatically stops if no motion key is received for 0.5 seconds.
