## 只修复本轮发现的问题

1. **MoveIt 热切换退出崩溃。** 控制器插件卸载顺序错误，使节点释放 action 客户端弱引用时段错误。独立复现原库退出 -11，修复后正常退出。参考 [MoveIt PR #3828](https://github.com/moveit/moveit2/pull/3828) 在项目私有目录编译 MoveIt 2.5.9 的单份轨迹执行管理器，保留 BSD 许可及溯源；只对项目 move_group 加载，不替换 `/opt/ros`。该 PR 核实时仍未合并。版本及公共头文件哈希不匹配会拒绝构建。
2. **第四旋钮复位后偶发收臂失败。** 原最终碰撞复查拒绝三个候选路径，任务失败。有效起点、同一现场规划场景的离线对照中，原检查精度 7/8 通过，细化后 8/8。只将 B 右臂 OMPL `longest_valid_segment_fraction` 从 0.005 调为 0.0005，保留最终碰撞复查和原安全阈值。细化会增加规划计算量，未增加固定空等；[官方说明](https://moveit.picknik.ai/humble/doc/examples/ompl_interface/ompl_interface_tutorial.html)解释了离散检查精度与时间的取舍。
3. **Gazebo 删除机器人时的传感器竞争。** 追加复测在删除旧机器人时遇到堆损坏退出 -6。独立测试另复现了删除模型与雷达更新的锁顺序死锁。现在先请求 SensorManager 完成目标机器人传感器的原生释放，确认已消失后再删除模型；失败则停止切换。无需重启或暂停世界。原堆损坏的具体写入点没有独立定位，修复后两轮未再复现，不宣称穷尽所有潜在内存问题。

验收同时检查动作、真实运动、几何、释放退出、收臂、终态和进程退出；不把请求接受或中间取消状态当作成功。没有修改碰撞几何、余量、关节限制或控件行程，也没有新增用户功能。
