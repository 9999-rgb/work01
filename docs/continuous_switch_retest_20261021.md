# 现有功能连续全量复测（2026-10-20—21）

修复本轮实际复现的问题后，同一 Gazebo 世界连续两轮通过：**108 项动作、32 次自主导航、78,602 帧几何检查**。场景／末端通过现有 Web 接口切换，世界进程和时钟在切换及两轮之间均未重启；验收结束后正常关闭测试实例。

## 本轮修复

- **B→A 退出段错误。** 先前轨迹执行管理器补丁之外，move_group 默认能力插件仍会先于主节点卸载。独立进程复现；GDB 的悬空虚表地址落在退出前映射的 `libmoveit_move_group_default_capabilities.so.2.5.9`。现在保留能力加载器直到主节点及回调组销毁之后再释放。项目私有编译 [MoveIt 2.5.9 的原程序](https://raw.githubusercontent.com/moveit/moveit2/2.5.9/moveit_ros/move_group/src/move_group.cpp)，不替换 ROS 安装；保留许可证、来源哈希和最小补丁。原程序首次探测即崩溃，修复程序独立退出 10/10 通过。
- **快速切换中的启动取消异常。** 规划器初始化期间收到 SIGINT，ROS 上下文已经关闭，后续创建发布者抛出 RCLError。仅对上下文已关闭的情况正常结束；上下文仍有效的初始化错误继续抛出。新增真实启动取消测试。
- **第二旋钮精确停靠超时。** 四柜和第一旋钮通过后，第二旋钮在机械臂尚未动作时超时；同一现场重试再次失败。同步采样证明指令基本持续非零、里程计与 Gazebo 真值一致，底盘在约 2–3 cm 残差处回弹。断困加力原来在约 2 mm 变化后立即撤掉，反复回到无法收敛的低速段。现在一次触发后保持原断困速度下限，直到进入原到位容差并停止、稳定。原速度上限、8 mm／0.07 rad 到位要求、五周期稳定判断及 45 s 超时不变。未改碰撞、几何、安全余量或工位。

第二旋钮定向转动／复位通过后，再从头跑两轮全量；两轮第二旋钮转动任务的停靠反馈结束于任务约 5.7／5.6 s，随后仍须完成机械操作、释放和收臂才计通过。
