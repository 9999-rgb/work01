## 变更与结论

- 摇杆转子保持原机构驱动。轨迹刷新间隔从 50 ms 改为 400 ms，避免反复替换加速段；目标速度 0.5 rad/s，取消仍每 20 ms 检查。此项已在 key005 中。
- 摇杆直线插入速度/加速度系数从 0.1 调为 0.3，实测从约 32.5 s 降至 11.58/11.56 s；对准门槛与到位检查保留。
- 插拔式旋钮拉出、插回系数从 0.25 调为 0.5，转动系数从 0.5 调为 1.0。仅作用于对应动作，按钮与抽拉柜流程不变。六个旋钮的 45°、回中共 12 项最终动作通过。
- fr4332 回中后腕部关节接近限位，原 40 mm 回撤路径只能完成 95%。退出目标改为 30 mm 后再由碰撞检查规划收臂，两个档位重测通过，未降低路径完成率要求。
- Web 操作菜单过滤有明确能力元数据但未开放操作的条目，仍显示已开放但需切换末端的目标。发电机层显示 4 按钮、6 旋钮和 1 摇杆；六个轴向反馈留在 API 与底层控制中，不独立显示。兼容旧目录的保守处理不变。

## 动作证据

摇杆先完成两轮提速启停，再在最终插入速度下完成整圈启动、停止退出和非零角度重新插入。最终两轮峰值约 0.568/0.563 rad/s，收臂最大误差小于 0.001 rad，端头退出距离约 1.51 m。整圈的墙钟耗时受仿真实时率影响，提速首轮约 23 s/1.03 圈，不能把设定速度当作实际墙钟速度。
