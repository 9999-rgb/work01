# 发电机层自主导航与控件回归（2026-10-16）

本轮只测试发电机层 B 末端；抽拉柜不在范围内。使用本机 amd64、ROS 2 Humble、Gazebo 11，经 Web API 发送导航和操作任务，不预定位、不直接修改控件关节。

## 检出与修复

基线中 fr135 正转接近路径只完成约 27%，fr12452 回中约 81%。旋转分支检查通过后，程序对多数旋钮仍保存原始 IK 种子；再次求解及规划失败后的自由姿态回退可能改变关节分支，使腕关节贴近限位。现保存完整路径校验实际得到的关节解，目标一致时直接使用该解；有已验证分支时仅在这些完整校验的不同构型间尝试进场规划，不回退到未经操作路径校验的姿态。扩大到全臂候选种子，并要求接近、操作、退出所有采样点均保留至少 3% 关节限位余量。

接触审计还捕获 fr25452→fbutton1 导航时，左摇杆转子与墙体代理短暂重叠约 9.06 mm。收拢工具实测在 body X 方向延伸到约 ±0.75 m，而导航 base_link 相对 body 旋转 -90°。发电机层 B 的局部和全局代价地图外形现沿 base_link Y 扩至 ±0.78 m，另保留原 0.03 m padding，覆盖收拢工具。仅扩大多边形仍捕获与柜体代理约 12.02 mm 重叠：DWB 原来只用 BaseObstacle，根据中心与膨胀代价评分。发电机层 B 增加 ObstacleFootprint，检查预测姿态的完整多边形；保留原中心膨胀评分。依据：[Nav2 官方说明](https://docs.nav2.org/jazzy/configuration_and_development/configuration_guide/controller_plugins/dwb_controller/trajectory_critics/obstacle_footprint/)。

## 复现

在已启动的发电机层 B 场景运行；采样进程必须采用与仿真相同的 ROS 域和网络配置。本机本轮为 domain 42、ROS_LOCALHOST_ONLY=0；麒麟容器使用自己的网络配置，不应照抄本机网络变量。

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=42 ROS_LOCALHOST_ONLY=0
python3 scripts/validate/validate_two_scene_web.py --phase generator --navigate \
  --out log/generator_navigation_validation/latest
```

`--navigate` 通过 `/task/navigate` 到站再操作；未指定该选项仍采用旧的仿真预定位。动作验收检查旋钮拉出、转角、插回、低速稳定，按钮行程与回弹，以及摇杆转动、停止、退出和收臂。接触审计使用实际实体姿态；顶点与开放网格距离采样不构成连续无碰撞的数学证明。

## 验收记录

本轮原始证据保存在 `log/generator_regression_20261015/`，不提交生成日志。`baseline/` 保留最初失败；`fixed/` 保留首轮 17 项动作结果；`repeat/` 保留重点控件复测及再次失败。`final/` 记录最终机械臂实现的六旋钮双向操作；`polygon/` 记录启用完整导航外形检查后的工位路线、第四旋钮双向复测、按钮和摇杆。先前动作虽曾全部成功，但导航接触检查检出重叠，不能据此声明全程几何通过。

重复回归又捕获 fr12452 回中对中失败：旧选择仅按操作末端评估余量，所选构型仅剩约 0.9%，1.123 mm 的对中修正无法完成。这次失败保留在 `repeat/`，不计为最终通过。

第二轮又捕获 fr2222 回中进场规划失败：操作链可行，但到达该构型的进场轨迹被柜体碰撞检查拒绝。现保留去重、排序后的多组完整可行构型，进场失败时换下一组，不在同一构型上反复空重试。失败证据位于 `attempt_before_transit_alternatives/`。

麒麟 ARM64 仍须拉取后重建镜像；`docker start/restart` 不会应用源码更新。


## 最终结果

同一最终机械臂实现分两段验收，导航配置在第二段启用完整多边形检查：

| 范围 | 结果 |
| --- | --- |
| 六旋钮正转、回中 | 12/12；每次操作期间的几何采样也通过 |
| fr12452 到站后额外正转、回中 | 2/2 |
| fbutton1–4 按压、回弹、收臂 | 4/4 |
| frb 整圈转动、停止、退出、收臂 | 1/1；实测 1.038 圈，停止后端头净空 1.515 m，收臂最大误差 0.000925 rad |
| 完整外形检查后的工位导航 | 11/11，包含原先擦碰的 fr12452→fr20422 及 fr25452→fbutton1 路线 |
| 完整外形检查后的接触采样 | 1,365 帧通过；柜体最小采样间隙 0.200 mm，接触部位最大采样穿入 0.058 mm，小于 1 mm 容差 |

第二旋钮回中再次触发第一构型进场路径被碰撞检查拒绝，切换到另一组已验证构型后成功，验证了分支恢复逻辑。第四旋钮回中从仅约 0.9% 的关节余量改善到本轮选中路径约 22.9%。

控制包编译通过；19 项相关配置、导航外形及运动学校验通过。证据索引为 `log/generator_regression_20261015/acceptance.json`。旧 `final/summary.json` 中的失败保留，表示启用完整导航外形检查前的综合批次；它不是本轮最终验收索引。各项跨批次证据按上表区分，未声称一次连续全套运行全部通过。

这些结果来自本机 amd64。尚未在麒麟 ARM64 上验证同样动作，也未证明任意初始位置、全部关节构型和无限次重复均成功。未调整接触阈值来掩盖失败，未直接设置控件关节终态。
